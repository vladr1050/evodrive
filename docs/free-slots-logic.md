# Логика свободных слотов в портале водителя

## Общая схема

1. **Неделя** — всегда Пн–Вс. «Текущая неделя» = неделя, в которой сегодня; «Следующая неделя» = +7 дней.
2. **Дни в прошлом** не показываются: если конец дня (23:59) уже прошёл, колонка этого дня не обрабатывается — слотов для неё нет.
3. **Станции** — берутся все активные станции; у каждой есть машины (`FleetVehicle` с `home_station_id`). Слоты считаются **по станции**: для каждой станции отдельно по её машинам.
4. **Занятость** — только смены со статусом `Booked`. Из них строятся «заблокированные» интервалы: смена + даунтайм до и после (из политики смен).

---

## Как считаются «свободные» окна

Для **каждого дня недели** и **каждой станции**:

- По **каждой машине** станции считаются смены, пересекающие этот день.
- Для каждой смены блокируется: `[начало − даунтайм, конец + даунтайм]` (в минутах от 00:00 этого дня).
- Дополнительно блокируются: конец дня, если в 00:00 следующего дня начинается смена; начало дня, если в 00:00 этого дня заканчивается смена.
- По заблокированным отрезкам считаются **дыры** — свободные интервалы в минутах от полуночи (например `[0, 420]` = 00:00–07:00, `[1140, 1440]` = 19:00–24:00).
- Интервалы **объединяются по всем машинам** станции (объединение множеств), затем выравниваются по сетке `time_slot_minutes` (например 15 мин).
- Для **сегодня** свободное время обрезается: показывается только от «текущего момента», округлённого вверх до следующего слота.

В итоге для каждого (день, станция) есть список свободных интервалов в минутах, например для одного дня: `[0, 420], [1140, 1440]`.

---

## Какие слоты показываются

- **Минимальная длительность** и **разрешённые длительности** задаются в политике смен (например мин. 4 ч, разрешены 4, 6, 8, 10, 12 ч).
- Показываются только слоты, для которых **хотя бы одна машина** станции свободна на всё выбранное время (с учётом даунтайма и лимитов политики).

### 1. Слоты в рамках одного дня

- Для каждого свободного интервала дня перебираются возможные **начала** с шагом не больше 60 мин (чтобы при большом `time_slot_minutes` не пропустить реальное свободное окно после выравнивания по сетке).
- Для каждого начала проверяется: есть ли разрешённая длительность (например 8 ч) и свободна ли хотя бы одна машина на этот отрезок.
- Если да — в список добавляется **один** слот (первый подходящий старт в этом интервале).
- Слот привязан к **этому дню** и показывается в колонке этого дня (например «Вт 10 Mar»).
- Для «сегодня» дополнительно: слот показывается только если его **начало** ещё в будущем.

### 2. Ночные слоты (переход через полночь)

- **Слот «начинается в этот день»**  
  Свободный хвост дня N (интервал, доходящий до 24:00) склеивается со свободным началом дня N+1 (интервал от 00:00).  
  Пример: Вт 19:00–24:00 + Ср 00:00–09:00 → один слот «19:00 – 07:00 (+1)» (или другая длина по политике).  
  Такой слот привязан к **дню N** (вторник) и показывается в колонке **вторника**.

- **Слот «заканчивается в этот день»** (день N уже в прошлом)  
  Если при просмотре день N−1 **пропущен** (он в прошлом), то ночной слот «(N−1) вечер → N утро» показывается в колонке **дня N**, чтобы его всё ещё можно было увидеть.  
  Показывается только если **конец** слота ещё в будущем (иначе слот уже недоступен).

## Пример: станция «Ignitis Jaunmoku iela 24a, Rīga»

По скрину админки (только Booked):

| Дата       | Начало | Конец  | Длительность |
|-----------|--------|--------|--------------|
| 10.03.2026 | 08:00 | 18:00 | 10 ч         |
| 11.03.2026 | 10:00 | 18:00 | 8 ч          |
| 13.03.2026 | 10:00 | 18:00 | 8 ч          |
| 14.03.2026 | 15:00 | 15.03 01:00 | 10 ч   |
| 16.03.2026 | 07:00 | 13:00 | 6 ч          |
| 16.03.2026 | 15:00 | 17.03 03:00 | 12 ч  |
| 17.03.2026 | 08:00 | 18:00 | 10 ч         |

(Предполагаем одну машину на этой станции и даунтайм, например, 1 ч.)

### Что должно быть свободно

- **10.03 (Вт)**  
  - До 08:00 и после 18:00 с учётом даунтайма (например 07:00–19:00 занято) → свободно 00:00–07:00 и 19:00–24:00.  
  - В колонке **вторника**: слот в течение дня (если есть кусок ≥ мин. длительности) и **ночной слот** 19:00 (10.03) – 07:00 (11.03) или подобный (длительность по политике, например 10 или 12 ч), с отображением конца как «07:00 (+1)».

- **11.03 (Ср)**  
  - Занято 10:00–18:00 + даунтайм → свободно 00:00–09:00 и 19:00–24:00.  
  - В колонке **среды**: утренний слот (например 00:00–08:00 или 06:00–10:00 в зависимости от политики), вечерний слот (например 19:00–…), при необходимости ночной на 12.03.

- **12.03 (Чт)**  
  - Нет смен 12.03 → весь день свободен (с учётом даунтайма после 01:00 от смены 14.03 15:00–15.03 01:00 — эта смена «задевает» 12.03 только даунтаймом с 15.03 01:00, т.е. не блокирует 12.03).  
  - В колонке **четверга**: целый день доступен для слотов (несколько слотов по длительностям).

- **13.03, 14.03, 16.03, 17.03** — по тому же принципу: свободные окна = день минус (смены + даунтайм), в колонке дня показываются слоты длиной ≥ мин. и из разрешённых.

### Ночь на 11.03

- **Окно**: 10.03 после 18:00 (с даунтаймом, например с 19:00) до 11.03 до 10:00 (с даунтаймом, например до 09:00).  
- Это один непрерывный свободный отрезок через полночь.  
- Ожидаемое поведение: в портале водителя в колонке **вторника 10.03** должен быть один ночной слот вида «19:00 – 07:00 (+1)» (или другая допустимая длительность), так как слот **начинается** во вторник.

Если этот слот **не отображается**, возможные причины:

1. **Вторник уже в прошлом**  
   При просмотре в среду 11.03 колонка вторника не строится. Тогда тот же ночной слот может показываться только в колонке **среды** (логика «заканчивается в этот день») и только пока конец слота (например 07:00 среды) ещё не наступил.

2. **Станция без машин или машина не привязана**  
   В `FleetVehicle` у станции «Ignitis Jaunmoku iela 24a» должен быть хотя бы один активный автомобиль с `home_station_id` = эта станция. Иначе для неё не будет ни свободных интервалов, ни слотов.

3. **Политика смен**  
   Проверить `min_duration_hours` и `allowedDurations()`: если минимальная длительность больше имеющегося окна (например окно 10 ч, а минимум 12 ч), слот не будет создан.

4. **Проверка доступности машины**  
   Слот добавляется только если `availableVehicleIdsForSlot()` для этого (станция, начало, конец) возвращает не пусто. Если из-за даунтайма или лимитов ни одна машина не проходит — слот не показывается.

## Разбор по коду: почему не появлялись 10.03 и 13.03

### Цепочка для «сегодня» (10.03)

1. **freeByDay** для вторника считается с `cutoffNow = now` → свободное время только с «сейчас» (округлённо). Для смены 08:00–18:00 и даунтайма 1 ч получается интервал **19:00–24:00** (в минутах `[1140, 1440]`).
2. В **computeStationFreeIntervals** интервалы выравниваются по сетке `time_slot_minutes`:  
   `aAligned = floor(startMin / slotMinutes) * slotMinutes`.  
   При **time_slot_minutes = 480** (8 ч): `aAligned = floor(1140/480)*480 = 960` (16:00). То есть интервал в коде становится **16:00–24:00**, хотя по факту машина свободна только с 19:00.
3. В цикле по началам слотов шаг был **slotMinutes** (480). Перебирались только 16:00 и 16:00+480=24:00. 24:00 уже за концом интервала, поэтому по сути проверялось только начало **16:00**. Слот 16:00–20:00 не проходит проверку доступности (даунтайм до 19:00), **19:00** мы не перебирали → слот для 10.03 не добавлялся.
4. Аналогично для **13.03**: вечерний интервал 19:00–24:00 после выравнивания давал начало 16:00, при шаге 480 мы снова не доходили до 19:00 → вечерний слот в пятницу не появлялся.

### Исправление

Шаг перебора начал слотов ограничен: используется **min(slotMinutes, 60)**. Тогда при любом `time_slot_minutes` перебираются хотя бы каждый час (16:00, 17:00, 18:00, **19:00**, …), и слот, начинающийся в 19:00, находится и добавляется.

---

## Кратко

- Свободные слоты = свободные от смен (с учётом даунтайма) окна по каждой станции и каждому дню, с учётом «сегодня» и прошлых дней.
- Ночной слот 10.03→11.03 привязан к **вторнику** и должен показываться в колонке «Вт 10 Mar» как «19:00 – 07:00 (+1)» (или с другими границами по политике).
- Если его нет — проверять: активные машины станции, политику длительностей и то, не попал ли вторник в «прошлое» при текущем дне просмотра.
